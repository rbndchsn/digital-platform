# clips/ — your screen recordings

One file per clip, named `<id>-<two-words>.mp4`, for example `C18-issuance.mp4`, `C17-refused-decision.mp4`. The ids are in `../03-shot-list.md`. Record at 1920 × 1080 (the 1440 × 900 browser window centred on ink, see `../06-production-guide.md`). Keep the raw OBS files too. This folder is git-ignored.
