# Video marketing kit

> **Superseded.** This is the first, single 7-minute kit. The current package (teaser + 10-minute film, generated scripts, rendered cards and motion) is one folder up; start from `../README.md`.

Everything needed to record the VERIFASSUR_X product video from the live demo.

| File | Use it for |
|---|---|
| `video-script.md` | The full script: scene by scene, with timecodes, what is on screen, what you click, and the narration. Read this while recording or in post. |
| `teleprompter.txt` | Narration only, large plain text, one scene per block. Load it in a teleprompter app or a second screen. |
| `shot-list.md` | The recording order as a table: persona, URL, clicks, duration, what the viewer must see. Tick as you go. |
| `production-checklist.md` | Before / during / after: demo reset, window size, recording settings, audio, pacing, captions, export, thumbnails, the three cuts (30 s, 2 min, full), legal notes. |
| `../marketingimages/` | Stills for the thumbnail, the brief and the end card. |

Three cuts are planned from one recording session:

1. **Teaser, 30 seconds** (social, e-mail signature): scenes 1, 4 and 9.
2. **Short, 2 minutes** (sales e-mail, LinkedIn): scenes 1–4, 6, 9.
3. **Full, about 7 minutes** (website, investor and client meetings): all scenes.

Start with `production-checklist.md`, record following `shot-list.md`, narrate from `teleprompter.txt`.
